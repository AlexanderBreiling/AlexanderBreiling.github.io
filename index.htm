As part of my undergraduate program at Worcester Polytechnic Institute I solved the Forward and Inverse Kinematics of a 3 degree of freedom robot by calculating the jacobian and using the DH method. I then generated the trajectories mathematically. I also calibrated the camera using a chessboard and employed color thresholding to determine which objects go where.

Unified Robotics II
I worked on a team of 3 to create a frontier exploration and slam algorithm in ROS using python and C++ in an ubuntu environment. I simulated a maze in gazebo and had a lidar equipped "turtlebot" autonomously explore and map the environment, after which it could path plan to any point in the maze using A*. The purple region indicates C space, Red indicates the nearest frontier, and blue indicates the path.
